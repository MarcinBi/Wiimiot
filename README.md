# Wiimiot

A Wii Remote shell based smart remote project for controlling a computer and IoT devices with an ESP32.

## Current goals
- Button-controlled PC commands
- Motion controls with an IMU
- Haptic feedback
- IR features later
- Custom PCB to fit inside a Wii Remote shell

## Repo structure
- `firmware/` - ESP32 code
- `docs/` - notes, plans, teardown info, and build progress

## Status
Early prototype stage.
